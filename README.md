# Monthly-Sales-Dataset-Kaggle-
Major Project: Time-Series Analysis of Sales & Demand Forecasting

Project Overview

This project is part of the Data Science internship at Skillairo Edutech. Poor demand forecasting often leads to severe inventory and revenue losses for businesses. The objective of this project is to analyze historical monthly sales data, understand underlying patterns like seasonality and trends, and apply statistical modeling to accurately forecast future demand.

Dataset

Source: Monthly Sales Dataset (Kaggle)

Description: Contains historical monthly sales records used for tracking time-based performance and predicting future trends.

Tools & Technologies Used

Language: Python

Libraries: Pandas, Statsmodels, Matplotlib

Techniques: Time-Series Analysis, Statistical Forecasting, Demand Prediction

Project Workflow

Data Preparation: Loaded the chronological data, set datetime indexes, and ensured a consistent frequency for time-series modeling.

Decomposition & Analysis: Analyzed the time-series components to extract the underlying trend, seasonal spikes, and residual noise.

Forecasting Model: Applied time-series forecasting techniques (e.g., ARIMA/SARIMA) using statsmodels to predict future demand.

Evaluation: Evaluated the forecast accuracy against historical patterns and plotted the predicted sales trajectory.

Business Implications: Translated the forecast model into actionable business strategies for inventory and revenue management.
